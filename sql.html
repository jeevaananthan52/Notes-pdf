Introduction to SQL

Structured Query Language: The Language of Databases

What is SQL?

SQL (Structured Query Language) is a standard programming language used to manage and manipulate relational databases. It allows users to create, read, update, and delete data in databases. SQL is essential for working with data in applications, websites, and business systems.

Basic SQL Commands

SQL commands are divided into several categories:

  • Data Definition Language (DDL): CREATE, ALTER, DROP
  • Data Manipulation Language (DML): SELECT, INSERT, UPDATE, DELETE
  • Data Control Language (DCL): GRANT, REVOKE
  • Transaction Control Language (TCL): COMMIT, ROLLBACK

SQL Examples

Creating a Table

CREATE TABLE users (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    email VARCHAR(100)
);

Inserting Data

INSERT INTO users (id, name, email) VALUES (1, 'John Doe', 'john@example.com');

Selecting Data

SELECT * FROM users;

Updating Data

UPDATE users SET email = 'john.doe@example.com' WHERE id = 1;

Deleting Data

DELETE FROM users WHERE id = 1;

Benefits of SQL

  • Standardized language across different database systems
  • Efficient data retrieval and manipulation
  • Supports complex queries and data analysis
  • Integrates well with programming languages
  • Provides data security and integrity
